# Известные ограничения

## Поиск по сохранённым чанкам

Текстовый и векторный поиск по `chunks.text`, в том числе инструменты RAG, рассчитаны на **0% перекрытия текста при разбиении**. При перекрытии одинаковый отрывок может занять несколько позиций в выдаче и вытеснить другие результаты.

Используйте `CHUNK_OVERLAP_PERCENT=0`. При другом значении API поднимает исключение и возвращает HTTP 503 до запуска поиска, а воркер отказывается начинать индексацию.

## qryn-view и Loki

Сервис `qryn-view` отключён в `compose.yaml`. Эта заметка описывает сохранённую конфигурацию прокси.

Caddy внутри контейнера `qryn-view` отдаёт веб-интерфейс на `http://127.0.0.1:3101` и проксирует запросы на чтение к Loki по внутреннему адресу `http://loki:3100`. Правила прокси находятся в [Caddyfile](observability/qryn-view/Caddyfile).

Прокси исправляет два параметра, из-за которых Loki возвращал `HTTP 400`.

- **Направление сортировки.** qryn-view может отправить `direction=backwards` или `direction=forwards`. Loki принимает `backward` и `forward`, поэтому Caddy заменяет значения перед отправкой запроса.
- **Шаг на длинном диапазоне.** qryn-view передаёт `step` даже при чтении строк логов. При диапазоне 12 часов и шаге 1 секунда получается 43 200 шагов, что превышает лимит Loki в 11 000 точек на ряд. Caddy удаляет `step` из запросов к `/loki/api/v1/query_range`, если выражение LogQL начинается с селектора потоков `{…}`. Для запросов метрик параметр `step` сохраняется.
