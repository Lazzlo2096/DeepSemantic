# Журнал изменений DeepSemantic

## [2026-11-10] - RAG с инструментами поиска

- Режим «Поиск по RAG» на главной странице отправляет запрос в LLM. Модель сама выбирает векторный поиск, буквальный поиск по тексту или чтение исходного документа.
- Оба инструмента поиска возвращают текст чанка и координаты в документе. Векторный поиск также возвращает оценку сходства.
- Инструмент чтения возвращает до 1500 символов статьи или суммаризации по ID и диапазону `[source_start, source_end)`. В ответе RAG отображаются ссылки на использованные фрагменты и их координаты.

## [2026-11-08] - Импорт HTML из arXiv

- Воркер выбирает формат источника через `ARXIV_SOURCE_FORMAT=pdf|html`. По умолчанию используется PDF с извлечением текста через `pypdf`.
- В режиме HTML воркер сохраняет исходную страницу и Markdown в RustFS. Markdown включает заголовки, формулы LaTeX, таблицы, подписи и ссылки на рисунки.
- Markdown-фрагменты сохраняются в `chunks.text` с переносами строк. При успешной смене формата для уже загруженной статьи воркер заменяет её чанки.
