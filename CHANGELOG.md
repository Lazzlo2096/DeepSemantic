# Журнал изменений DeepSemantic

## [2026-11-08] - Импорт HTML из arXiv

- Воркер выбирает формат источника через `ARXIV_SOURCE_FORMAT=pdf|html`. По умолчанию используется PDF с извлечением текста через `pypdf`.
- В режиме HTML воркер сохраняет исходную страницу и Markdown в RustFS. Markdown включает заголовки, формулы LaTeX, таблицы, подписи и ссылки на рисунки.
- Markdown-фрагменты сохраняются в `chunks.text` с переносами строк. При успешной смене формата для уже загруженной статьи воркер заменяет её чанки.
