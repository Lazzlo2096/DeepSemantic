# Журнал изменений DeepSemantic

## [2026-11-14] - Подключение LangSmith Studio

- Добавлен отдельный сервис `studio` в Docker Compose и команды `just studio-up`, `studio-down`, `studio-logs`.
- Граф RAG доступен в Studio через Agent Server: визуализация, просмотр промежуточного состояния, остановки и продолжение выполнения. Для ввода вопроса используется поле `question`.
- Узлы и переходы поиска общие с API; адаптер подготавливает контекст и сохраняет состояние в формате, совместимом с checkpoints. История Studio хранится в отдельном Docker volume, облачная трассировка отключена.
- Добавлены проверки схемы, восстановления состояния, повторных вопросов и освобождения ресурсов. Существующий журнал запусков сайта сохранён.

## [2026-11-13] - RAG на LangChain и LangGraph

- Ручной цикл поиска заменён графом LangGraph с узлами сбора источников, выполнения инструментов и формирования ответа.
- Вызовы модели RAG выполняются через LangChain `ChatOpenRouter`, инструменты — через `StructuredTool`, ответ запрашивается с JSON Schema.
- Сохранены два промпта, поиск по статьям и суммаризациям, проверка ссылок, журнал шагов и существующий контракт API.
- Обновлены зависимости и Docker-сборка API. Добавлены проверки графа с подставными ответами OpenRouter; все 22 теста проходят на Windows и в Linux-контейнере.

## [2026-11-12] - Переход на облачный инференс через OpenRouter

- Полностью отказались от локального инференса в пользу облачного через OpenRouter: генерация ответов RAG, суммаризация и эмбеддинги выполняются через его API.
- Удалены Ollama, локальный `embeding-service`, GPU-конфигурации и зависимости для локального инференса. API и воркер индексации запрашивают эмбеддинги напрямую у OpenRouter.
- Обновлены конфигурации запуска, переменные окружения, интерфейс управления воркерами и документация.

## [2026-11-10] - RAG с инструментами поиска

- Режим «Поиск по RAG» на главной странице отправляет запрос в LLM. Модель сама выбирает векторный поиск, буквальный поиск по тексту или чтение исходного документа.
- Оба инструмента поиска возвращают текст чанка и координаты в документе. Векторный поиск также возвращает оценку сходства.
- Инструмент чтения возвращает до 1500 символов статьи или суммаризации по ID и диапазону `[source_start, source_end)`. В ответе RAG отображаются ссылки на использованные фрагменты и их координаты.

## [2026-11-08] - Импорт HTML из arXiv

- Воркер выбирает формат источника через `ARXIV_SOURCE_FORMAT=pdf|html`. По умолчанию используется PDF с извлечением текста через `pypdf`.
- В режиме HTML воркер сохраняет исходную страницу и Markdown в RustFS. Markdown включает заголовки, формулы LaTeX, таблицы, подписи и ссылки на рисунки.
- Markdown-фрагменты сохраняются в `chunks.text` с переносами строк. При успешной смене формата для уже загруженной статьи воркер заменяет её чанки.
