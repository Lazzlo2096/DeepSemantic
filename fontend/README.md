# Каталог статей arXiv

Из корня DeepSemantic запусти `docker compose up -d fontend` и открой страницу каталога. При необходимости порт задаётся переменной `FONTEND_PORT`. [Локальный каталог](http://127.0.0.1:8080)

Страница читает `GET /papers` через локальный прокси Caddy и показывает заголовки, авторов, даты подачи и аннотации. Ссылка в заголовке ведёт к оригиналу на arXiv. Страница показывает по 12 записей и сортирует их в порядке, полученном от API.

Поле «Поиск по смыслу» отправляет запрос в `POST /chunks/search`. API принимает `query` и необязательный `limit` от 1 до 50 (по умолчанию 10). Результаты содержат текст чанка, оценку сходства и данные статьи, если она связана с чанком. Для наполнения индекса запусти `docker compose run --rm --no-deps api python -m paper_embeddings`.
